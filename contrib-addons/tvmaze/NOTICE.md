# TVmaze data

TVmaze supplies the episode data. Its API terms require source credit and the CC BY-SA license. Each result has the public episode URL and a source credit. The host must show this credit with the metadata or in its source view.

See the [TVmaze API terms](https://www.tvmaze.com/api#licensing) and the [CC BY-SA license](https://creativecommons.org/licenses/by-sa/4.0/).

The GPL license in `LICENSE` applies to this package's code. It does not replace the terms for TVmaze data.
