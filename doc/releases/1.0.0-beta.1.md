Windows x86_64 portable build, macOS Intel and Apple Silicon app bundles and disk images, and Linux x86_64 portable archive
Git tag: `1.0.0-beta.1`

**Full Changelog**: https://github.com/hakone-org/hakone/compare/4.0.0-beta.5...1.0.0-beta.1

VLC Juxtopposed is now **Hakone**. Hakone continues adapting [Juxtopposed](https://www.juxtopposed.com/)'s [VLC design](https://www.figma.com/community/file/1691465999134370980/vlc-redesign) for the native player, built on the VLC media player engine. With the new name, Hakone starts its own version numbers: this is `1.0.0-beta.1`, codename Jiji. It follows `4.0.0-beta.5`; update notifications in earlier builds point here.

**Changes since `4.0.0-beta.5`:**

- Rename the app to Hakone, with a new logo, a `hakone` executable, `Hakone.app` on macOS and `hakone-…` downloads. The project now lives at [github.com/hakone-org/hakone](https://github.com/hakone-org/hakone).
- Keep Hakone's settings, media library and add-on data apart from an installed VLC. On its first start, Hakone copies the settings and library of earlier VLC Juxtopposed builds into its own folders. VLC 3 settings are left alone.
- Version Hakone separately from the VLC engine. `--version` and the debug log show both, for example Hakone `1.0.0-beta.1` with LibVLC `4.0.0-dev`.
- Add add-ons. Each add-on runs in an isolated worker with limits on memory and time, and needs your permission to use the network, accounts or your media. The **Extensions** settings page lists installed add-ons, their settings and recent worker crashes; a worker that keeps crashing is paused.
- Browse, install and update add-ons from the Hakone registry. A new version must start cleanly before it is offered, and one that crashes soon after updating is replaced by the previous version. Updates to bundled add-ons are offered at startup.
- Bundle four add-ons: **Episodes**, the episode panel in the player, now translated into French, Spanish, Japanese, Simplified Chinese and Russian; **TVmaze** episode titles; **Radio Browser** internet radio under **Network → Radio**; and **TheSubtitleDB** subtitle search.
- In Episodes, choose which series an episode belongs to with **Episode options → Choose series…**. Later lookups use the saved choice.
- Refresh the artwork of a single item. Load library artwork more smoothly and keep thumbnails while scrolling. While a list loads, keep the toolbar in place and say "Loading" instead of showing an empty library. Keep network sources loading until they first respond.
- Refine the General and Extensions settings layouts and accent contrast. Keep keyboard focus visible in the streaming wizard and VLM editor, keep source and conversion forms usable at large display scales, and keep secondary panels readable on small screens. Improve compact file selection and capture options, and recover from failed library folder additions and VLM configuration exports.
- Keep the interface responsive by moving add-on reads and writes, folder watching, filename parsing, subtitle provider preparation and, on Windows, font loading off the interface thread. Close windows at once when quitting, and stop playback and interrupt Windows network-file reads before cleanup.
- Fix a crash when quitting while a file or folder chooser is open.
- Include upstream playback fixes: play animated GIFs through FFmpeg, respect AV1 picture orientation, keep DVD timestamps correct across seamless cell changes and multi-angle titles, keep HTTP authentication across retries, and stop transparent overlay pixels from changing RGB video.
- Publish a drag-to-install disk image for each Mac download alongside the ZIP.

**Use:**

- Close earlier VLC Juxtopposed windows before starting Hakone. Hakone installs alongside earlier builds instead of replacing them; once your settings have carried over, you can delete the old app. Keep each download's complete contents together.
- Windows 10 (1809 or later) / Windows 11, x64: extract `hakone-1.0.0-beta.1-win64.zip`, then open `hakone-win64/hakone.exe`. The empty `portable` folder stores settings beside the app. To reuse portable settings from an earlier build, copy your previous `portable` folder while the app is closed, then rename the `vlc` folder inside it to `hakone`.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel. Open the DMG and drag Hakone to Applications, or extract the ZIP and move `Hakone.app` into a folder of your choice. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it.
- Linux: extract `hakone-1.0.0-beta.1-linux-x86_64.tar.gz`, then run `AppDir/AppRun`. Keep the complete `AppDir` folder together. The build targets glibc 2.35 or later (Ubuntu 22.04 or equivalent) and does not require FUSE.
- Update notifications open the matching release page. Downloading and replacing the application remains manual.
- Verify downloads against `SHA256SUMS.txt` if desired. The table below identifies the exact source commit for each package; detailed build metadata remains in the workflow artifacts.

**Current limits:**

- Add-ons are new. Some built-in providers stay in the core until their add-on replacements pass the tests.
- The redesign is in progress. These are experimental builds; platform coverage does not mean every playback path has been tested.
- Windows executables have no trusted publisher signature. Mac apps are ad-hoc signed without a Developer ID signature or Apple notarization. Operating systems may warn or block the first launch.
- Mac downloads are separate native builds; choose the correct architecture. Build metadata records the minimum supported macOS version.
- Linux still uses the host's graphics drivers and desktop/audio services; behavior can vary between distributions.
- HDR and maximum resolution settings apply to the next video. Some advanced flows still use the older VLC interface.
- Previews for large videos or network files can take time, and decoding can still fail.
- The media library database must be on a local drive; media folders may be on a network share.
- Episode and subtitle matching depends on the available filenames and metadata. Saved folder rules support local tracks for future episodes; future online subtitle searches are not automatic.
